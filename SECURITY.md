# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.1   | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in this mod, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Email the maintainer or use [GitHub's private vulnerability reporting](https://github.com/CodeMaster013/dtstilllife/security/advisories/new)
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Scope

This is a Minecraft mod. Security issues are limited to:
- Game crashes or instability caused by the mod
- Unexpected behavior that could affect world integrity
- Resource processing issues (memory, CPU) that could affect servers

This mod does **not** handle user data, network connections, authentication, or any external services.

## Response Time

We will acknowledge reports within 48 hours and aim to provide a fix or mitigation plan within 1 week for confirmed issues.
